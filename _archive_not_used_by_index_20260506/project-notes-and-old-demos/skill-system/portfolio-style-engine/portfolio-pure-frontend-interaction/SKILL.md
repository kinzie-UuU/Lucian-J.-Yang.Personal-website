# Portfolio Pure Frontend Interaction

Use this family when the site should prove control over the medium itself.

## Core Signals

- SVG path deformation
- DOM / CSS transform depth
- pseudo-3D spaces
- authored hover / scroll behavior
- web-native motion logic

## Best For

- creative developers
- interaction-heavy portfolios
- experimental but readable studio sites

## Risks

- identity mismatch for non-developers
- maintenance complexity
- content can be overshadowed

## For Non-Developer Users

Borrow only:

- interaction grammar
- depth discipline
- selective SVG / DOM techniques

Do not borrow:

- developer self-positioning
- spectacle as default identity
