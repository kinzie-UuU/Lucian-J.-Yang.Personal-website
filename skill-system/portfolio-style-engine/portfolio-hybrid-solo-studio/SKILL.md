# Portfolio Hybrid Solo Studio

Use this family when the user needs to look:

- capable
- complete
- focused
- professionally broad but not inflated

## Core Signals

- selected work first
- compact but sharp self-intro
- capability clarity
- proof of range without clutter

## Best For

- solo designers
- one-person studios
- multidisciplinary creatives
- consultants with execution depth

## Risks

- too many capabilities create soup
- easy drift into creative-developer identity if technical services dominate the language
