# Portfolio Concept Coherence

Use this family when one concept can organize the site deeply.

## Core Signals

- repeated conceptual vocabulary
- concept shapes copy and process framing
- concept influences section rhythm and CTA wording
- site feels unified rather than merely themed

## Best For

- boutique studios
- personality-led practices
- strong-brand personal sites

## Risks

- can become gimmicky
- can weaken trust if the metaphor is decorative rather than functional
