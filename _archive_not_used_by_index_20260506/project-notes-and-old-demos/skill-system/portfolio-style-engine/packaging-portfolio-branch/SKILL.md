# Packaging Portfolio Branch

Use this branch when the user's core value is not only making packaging beautiful, but making it right under real constraints.

## Express

- judgment under constraints
- OEM / gifting / channel awareness
- material and structure logic
- production, process, and delivery awareness
- AI as acceleration, not as replacement for judgment

## Prefer

- layered reveal
- comparison structures
- filtering as visible judgment
- system language
- material-aware interaction

## Avoid

- generic "creative person" language
- over-gamified navigation
- over-developer-coded identity
- interaction unrelated to packaging thinking

## Good Homepage Logic

The homepage should quickly communicate:

- what packaging situations the user handles
- what kind of decisions they are good at
- why their taste is trustworthy in real conditions
