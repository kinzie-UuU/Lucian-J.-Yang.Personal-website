# Portfolio 100 Audit

This folder tracks the rigorous audit of Muzli's "Top 100 Most Creative and Unique Portfolio Websites of 2025".

Goal:

- read the list as a research corpus, not as loose inspiration
- extract recurring portfolio design logic
- map recurring logic into future Codex skills
- keep all findings grounded in auditable notes

Primary source:

- Muzli article:
  `https://muz.li/blog/top-100-most-creative-and-unique-portfolio-websites-of-2025/`

## Research Standard

We are intentionally using the strict path:

- not "sample and generalize"
- not "collect screenshots only"
- not "write skills too early"

Instead, each site should be reviewed with a minimum baseline:

1. identity of the creator/studio
2. first-screen structure
3. dominant visual thesis
4. dominant interaction thesis
5. navigation/control style
6. case-study presentation mode
7. material language
8. what is actually reusable as a skill
9. whether it suits Kinzie

## Audit Layers

The final taxonomy will be extracted across five layers:

1. visual thesis
2. interaction thesis
3. content architecture
4. material system
5. case presentation

## Deliverables

This audit should ultimately produce:

- a complete or near-complete site audit log
- a reusable portfolio taxonomy
- a list of future skill candidates
- a Kinzie-specific mapping
