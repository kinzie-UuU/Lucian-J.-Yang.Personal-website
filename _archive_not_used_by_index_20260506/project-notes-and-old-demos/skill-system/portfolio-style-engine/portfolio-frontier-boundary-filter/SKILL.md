# Portfolio Frontier Boundary Filter

Use this skill to reject bad fits.

## Reject or limit when

- the user is not selling immersive-tech capability
- the audience needs clarity
- the business goal is lead generation
- the content is not strong enough to justify the complexity
- the maintenance burden would be unreasonable

## Common Mismatches

- WebGL hero for a user who needs direct trust
- creative-developer identity for a packaging or brand designer
- game-like navigation for a service-business website
- immersive spectacle hiding the actual work

## Output

Always explain:

- what was rejected
- why it was rejected
- what risk it avoids
